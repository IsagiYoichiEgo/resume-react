# Портфолио alimbro — дизайн перед реализацией

Дата: 6 ноября 2026. Репозиторий: IsagiYoichiEgo/resume-react. Текущая база: React 19, TypeScript, Vite, публикация GitHub Pages на push в main. Отдельная рабочая копия создана в work/resume-react.

## Задача и аудитория
Клиенты из малого бизнеса должны быстро понять, кто такой Аброрбек, какие сайты и приложения он делает, увидеть реальные учебные проекты и связаться через WhatsApp. Запоминающийся элемент — оригинальный котик, который остаётся в поле зрения и реагирует на прокрутку. Пользователь выбрал тёмное оформление с объёмом и подсветкой. Нужны выразительные анимации, но понятные тексты и навигация.

## Подходы
1. Косметически обновить существующее резюме: быстрее, но сохраняет структуру для поиска стажировки и не решает запрос на креативное клиентское портфолио.
2. Полноценный WebGL-мир с тяжёлой сценой: выразительно, но усложняет работу на телефоне и затрудняет чтение.
3. Выбранная рекомендация: тёмная интерактивная мастерская. Крупная типографика, объёмная сцена первого экрана, продуманные движения при прокрутке, небольшое число содержательных разделов. Реализовать на существующем React с CSS perspective и лёгкой анимацией через requestAnimationFrame, без обязательного WebGL. Пользователь подтвердил тёмное направление; состав и реализация изложены здесь для проверки перед кодом.

## Визуальная система (предложение исполнителя)
Фон «ночь» #0A1020, поверхности #121C31, основной текст #F6F3EC, вторичный #AAB4C7, прохладная подсветка #7DE6D1, тёплый акцент #FFB788. Голос и тексты русские. Выразительный кириллический шрифт заголовков (например Unbounded), читаемый Golos Text для основного текста; конкретное подключение выбирает исполнитель. Большой первый экран с асимметричной композицией и одной запоминающейся объёмной сценой. Проектам — широкие разные по композиции обложки, а не одинаковые мелкие карточки. Декоративные элементы не закрывают текст.

## Котик и движение
Сгенерировать оригинального дружелюбного котика через imagegen: светлая шерсть с тёмными деталями, выразительные глаза, мягкий стилизованный 3D. Это элемент сайта, не питомец приложения Codex. Изображение с прозрачностью сохранить внутри public/assets, а не только в папке генератора. Для настоящего шага использовать спрайт с фазами ходьбы либо отдельные сгенерированные позы; выбранный технический способ остаётся исполнителю.
Котик закреплён у нижнего края экрана с отступами safe-area; на телефоне компактнее. При прокрутке идёт и меняет положение в ограниченной области, оставаясь в окне. После остановки отдыхает. При нажатии реагирует. Иногда показывает короткую реплику по контексту раздела; не чаще одного сообщения на несколько секунд. Примеры: «Мур. Посмотрим проекты?», «Лапка за любопытство», «Здесь можно написать Аброрбеку». Реплики не являются отзывами клиентов. Дать возможность спрятать реплику/котика и вернуть его; без звука и запросов уведомлений.
Другие эффекты: первая сцена меняет глубину/положение при прокрутке, обложки проектов реагируют на указатель на устройствах с мышью, переход к разделам плавный. Избежать перехвата прокрутки. При prefers-reduced-motion убрать ходьбу, параллакс и сильные преобразования, оставить доступный неподвижный контент.

## Ограничения и доступность
Сохранить рабочую публикацию на том же GitHub Pages и корректный BASE_PATH. Не менять чужие проекты/API и не публиковать тестовые объявления. Не генерировать фиктивные проекты, просмотры, опыт или продажи. Все обычные ссылки работают как ссылки; диалог закрывается Escape и возвращает фокус; кнопки доступны с клавиатуры. Текст читается при выключенной анимации. Никакой горизонтальной прокрутки на 390px. Котик не перекрывает основные кнопки и открытый диалог. Свести перерисовки при скролле к одному requestAnimationFrame, слушатели и таймеры очищать.

Затем обновить указанный репозиторий обычным обратимым коммитом, дождаться GitHub Actions и проверить опубликованную страницу. Не создавать новый Site и не менять адрес публикации.
