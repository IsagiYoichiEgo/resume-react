# Gentle portfolio light accents

Scope: user-selected hero words, header wordmark, Projects heading, and header contact action. Remove the complete name/avatar introduction above the hero title.

CSS-only implementation: cream text remains legible while a narrow mint/pearl highlight moves across it. 11–13 second cycles include long resting periods; the two hero lines and logo have staggered timing. The contact action has a thin orbiting light edge with a pause, plus a restrained hover/focus response. No flashing, opacity fades of content, new libraries or JavaScript timers.

Reduced-motion and forced-color preferences retain static readable text and clear controls. Text selection remains readable. Existing contacts, project content, layout structure and demos are unchanged.
